# Dossier pour les images du plugin

Placez votre logo ici: **RUNNWRITE-AI-LOGO-WHITE.png**

Le logo sera affiché dans la sidebar (menu latéral) de l'application.

## Spécifications recommandées:
- Format: PNG avec fond transparent
- Couleur: Blanc (pour contraster avec le fond sombre de la sidebar)
- Hauteur max: 40px (ajustement automatique)
- Largeur: Automatique (ratio préservé)
